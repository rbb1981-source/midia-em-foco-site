# Mídia em Foco

Landing page estática em HTML, CSS e JavaScript para divulgação da Mídia em Foco.

## Arquivos principais

- `index.html`: página principal do site
- `logo-symbol.jpeg`: símbolo usado no cabeçalho e no botão flutuante
- `logo.jpeg`: versão completa do logo

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie estes arquivos para a branch principal (`main`).
3. No GitHub, abra `Settings > Pages`.
4. Em `Build and deployment`, escolha:
   - `Source`: `Deploy from a branch`
   - `Branch`: `main`
   - `Folder`: `/ (root)`
5. Salve e aguarde o link público ser gerado.

## Visualização local

Abra o arquivo `index.html` no navegador.
